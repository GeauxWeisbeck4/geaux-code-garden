# Geaux Code Garden

Geaux Code Garden is a collection of notes, guides, tutorials, and more for Geaux Code, a publication and community for developers of all skill levels. Whether you're a beginner or an experienced developer, you'll find valuable resources to help you grow your skills and stay up-to-date with the latest technologies.

Topics include:
- Programming languages
- Computer Science fundamentals
- Data Structures and Algorithms
- Software Engineering
- Web Development
- System Design
- Databases
- DevOps
- Cloud Computing
- Machine Learning
- Artificial Intelligence

You can think of this as a personal knowledge base for GeauxCode.dev. Since we can't include all of our resources in our condensed posts, you can reference this site for more detailed information.

## Get Started

If you are interested in contributing to the Geaux Code Garden, you will need to download the repository and install the dependencies locally. Follow the instructions below to get started:

1. Clone the repository: `git clone https://github.com/geauxcode/geauxcode-garden.git`
2. Navigate to the project directory: `cd geauxcode-garden`
3. Install dependencies: `npm install` or `yarn install` or `pnpm install` or `bun install`
4. Start the development server: `npm run dev` or `yarn dev` or `pnpm dev` or `bun dev`
