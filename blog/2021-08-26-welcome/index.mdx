Welcome to the Geaux Code Garden, a place where you will find notes, tutorials, and other learning guides to assist
in your journey in learning computer science and software development. It is a companion site to the Geaux Code
Publication, a work in progress.

This site was created as a place to store resources and reference materials, especially while developing the Geaux
Code blog, community, and newsletter. The goal is to create a community driven garden of notes, tutorials, posts, and
 more that integrate knowledge from the Geaux Code Community of developers and provide a platform for sharing that
 knowledge with everyone who wants to learn more about the fascinating world of computer science, web development, and
 software engineering.
